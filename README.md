# Shield Crouch

Allows shielding on crouch, yupyup
But also contains small optional miscellaneous additions which don't fit in my other mods

- Impedes the usual right click interaction with the shield and replaces it with an automatic activation upon crouching
- Doesn't slow you down even more when shielding, you keep your crouching walk speed
- Also crouching in water whilst holding a shield will activate it
- Should be able to be enabled/disabled per client (the config on the server shouldn't apply it to connecting clients)

Miscellaneous Features (off by default):
Lethal_Poison: makes vanilla poison lethal by removing the 1 hp check to not kill the player
